# mill-box for Android

mill-box 的 Android 客户端(外壳工程 vendored 在本仓库的 `clients/android`)允许用户管理和运行
本地或远程 mill-box 配置文件,并提供平台特定的功能实现,例如 TUN 透明代理实现。

## :material-graph: 要求

* Android 5.0+

## :material-source-repository: 源代码

* [clients/android](https://github.com/swysgh/mill-box/tree/main/clients/android)(本仓库内)
