# 服务

### 结构

```json
{
  "services": [
    {
      "type": "",
      "tag": ""
    }
  ]
}
```

### 字段

| 类型              | 格式                                  |
|-------------------|---------------------------------------|
| `api`             | [sing-box API](./api)                 |
| `hysteria-realm`  | [Hysteria Realm](./hysteria-realm)    |
| `resolved`        | [Resolved](./resolved)                |
| `ssm-api`         | [SSM API](./ssm-api)                  |

#### tag

端点的标签。
